# ContextKeys - Thunderbird キーボードショートカット表示アドオン

Thunderbird のキーボードショートカットを、現在操作している画面の種類に応じて確認できるアドオンです。

## ✨ 機能

- **コンテキスト対応ショートカット表示**: メール、カレンダー、アドレス帳、タスクなど、現在の操作コンテキストに応じたショートカット一覧を表示
- **リアルタイム検索**: ショートカットキーや説明文で素早く検索可能
- **多言語対応**: 日本語環境と英語環境の両方に対応
- **ダークモード対応**: OS のダークモード設定に自動対応

## 🚀 インストール方法

### 前提条件
- Thunderbird 128.0 以上

### インストール手順

1. 本リポジトリから XPI ファイルをダウンロード（[Releases](../../releases) ページ）
2. Thunderbird を開く
3. メニューから「ツール」→「アドオン」を選択
4. アドオンマネージャーの右上の歯車アイコンから「ファイルからアドオンをインストール」を選択
5. ダウンロードした XPI ファイルを選択

## 💡 使い方

### 基本的な使用方法

1. Thunderbird で任意のタブを開く（メール、カレンダー、アドレス帳など）
2. **`Ctrl + Shift + H`** を押す
3. そのコンテキストで利用可能なショートカット一覧がポップアップで表示される
4. 検索ボックスで目的のショートカットを検索可能
5. **`Esc`** キーを押すか、ウィンドウを閉じると一覧が閉じる

### サポート対象コンテキスト

| コンテキスト | 説明 |
|-----------|------|
| **メール** | メール一覧、メッセージ表示、メール作成時のショートカット |
| **カレンダー** | イベント・スケジュール操作 |
| **アドレス帳** | 連絡先管理のショートカット |
| **タスク（ToDo）** | タスク・やることリスト操作 |
| **共通** | 検索、タブ移動など全画面共通機能 |

## 🔧 開発中の使用

### セットアップ

```bash
git clone https://github.com/yourusername/ContextKeys.git
cd ContextKeys
```

### ファイル構成

```
ContextKeys/
├── manifest.json              # WebExtension マニフェスト
├── background.js              # コンテキスト判定、ダイアログ管理
├── shortcut-dialog.html       # UI テンプレート
├── shortcut-dialog.css        # スタイル定義
├── shortcut-dialog.js         # ダイアログロジック
├── data/
│   └── shortcuts.json         # ショートカット定義（主要データファイル）
├── docs/
│   ├── prd.md                 # 要件定義書
│   └── thunderbird-keyboard-shortcuts.md  # 公式ショートカット参考資料
└── README.md                  # このファイル
```

### Thunderbird での開発モード読み込み

1. Thunderbird を起動
2. メニュー「ツール」→「アドオンとテーマ」→「拡張機能」
3. 右上の歯車アイコン → 「デバッグ用アドオン」
4. 「一時的なアドオンを読み込む」で `manifest.json` を選択
