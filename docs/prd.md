# Thunderbird ショートカットキー一覧表示アドオン

## 要件定義書

### 1. 文書概要

#### 1.1 目的

Thunderbirdには多数のキーボードショートカットが用意されているが、利用可能なショートカットは、現在表示している画面やフォーカス位置、操作状態によって異なる。

本アドオンは、ユーザーがThunderbirdを操作している際に `Ctrl + ?` を押すことで、**現在の画面・操作コンテキストに関連するショートカットキーを一覧表示する**ことを目的とする。

Gmailに存在するショートカット一覧表示機能を参考にするが、Gmailのショートカット体系をThunderbirdへ移植するものではない。

あくまで、Thunderbird本来のキーボード操作体系をユーザーが容易に確認できるようにすることを目的とする。

---

## 2. 背景

Thunderbirdはキーボードによる操作を広くサポートしている。

一方で、ショートカットキーは以下のような問題がある。

- 数が多く、すべてを記憶することが難しい
- メニューに表示されないショートカットも存在する
- メール一覧、メッセージ表示、メール作成画面などによって利用できる操作が異なる
- キーボードフォーカスの位置によって操作可能なキーが変わる場合がある
- 公式ドキュメントをWebブラウザーで開いて確認するのは操作中には煩雑
- スクリーンリーダー利用者にとって、視覚的なキーボード操作ガイドを探すことが難しい場合がある

そこで、

> **「今、自分が操作しているThunderbirdの画面では、どんなショートカットが使えるのか？」**

という疑問に、その場で答えられる仕組みを提供する。

---

## 3. 基本コンセプト

### 3.1 基本操作

ユーザーがThunderbird上で、

`Ctrl + ?`

を押す。

すると、

**「現在のコンテキストで利用可能なショートカットキー一覧」**

を表示する。

一覧を確認した後、ユーザーは一覧を閉じて元のThunderbird操作に戻る。

---

### 3.2 Gmailとの違い

Gmailのショートカット一覧機能を操作感の参考とする。

ただし、以下は本アドオンの目的としない。

- GmailのショートカットキーをThunderbirdに移植する
- ThunderbirdのショートカットをGmailと同じものに変更する
- Thunderbirdの既存ショートカットを置き換える

本アドオンの目的は、

> **Thunderbirdの既存のキーボード操作を「調べやすくする」こと**

である。

---

## 4. 対象ユーザー

主な対象は以下とする。

### 4.1 Thunderbirdをキーボード中心で操作するユーザー

マウスを使用せず、または使用頻度を減らしてThunderbirdを操作したいユーザー。

### 4.2 ショートカットキーを覚えながらThunderbirdを利用するユーザー

すべてのショートカットを暗記するのではなく、必要なときに一覧を確認したいユーザー。

### 4.3 スクリーンリーダー利用者

NVDA、Windows Narratorなどのスクリーンリーダーを利用してThunderbirdを操作するユーザー。

特にアクセシビリティを重視し、キーボード操作を主体とするユーザーにとって使いやすいUIを目指す。

---

## 5. 対象プラットフォーム

初期バージョンでは、

**Thunderbird デスクトップ版**

を対象とする。

対象OSはThunderbirdが公式にサポートするOSを基本とする。

ただし、開発初期では特定OSに依存する実装を避け、Thunderbird WebExtension APIを中心に実装する。

## 6. 機能要件

### FR-001 ショートカット一覧表示

ユーザーが `Ctrl + ?` を押した場合、ショートカットキー一覧を表示する。

#### 期待する操作

```text
Ctrl + ?
    ↓
ショートカット一覧表示
    ↓
一覧を確認
    ↓
Esc
    ↓
Thunderbirdの元の画面へ戻る
```

---

### FR-002 現在のコンテキストを判定する

一覧表示時に、Thunderbirdの現在の操作コンテキストを判定する。

**MVP（最小実装版）対象の3つのコンテキスト**：

- メール一覧（mail-list）
- メッセージ表示（message-view）
- メール作成（message-compose）

**将来の拡張予定**：

- アドレス帳
- 検索結果画面
- カレンダー
- ニュースグループ

---

### FR-003 コンテキストに応じたショートカットを表示する

現在のコンテキストに関連するショートカットのみを優先的に表示する。

#### メール一覧

- メッセージ移動（↑/↓、N、P、T など）
- メッセージ操作（Enter、Delete、R、A、F など）
- タグ・マーク（S、M、1～9 など）
- 検索と絞り込み（Ctrl+Shift+K など）

#### メッセージ表示

- 返信・転送（Ctrl+R、Ctrl+Shift+R、Ctrl+L など）
- メッセージ移動（F、B、N、P、T など）
- メッセージ管理（Delete、Ctrl+S、Ctrl+P など）
- タグ・マーク（S、M、1～9 など）

#### メール作成

- 送信・保存（Ctrl+Enter、Ctrl+Shift+Enter、Ctrl+S など）
- テキスト編集（Ctrl+B、Ctrl+I、Ctrl+U、Ctrl+Z など）
- 添付ファイル（Ctrl+Shift+A、Alt+↑/↓ など）
- 書式設定（Ctrl+]、Ctrl+[ など）

実装は Mozilla Thunderbird 公式ドキュメントを基準とする。

---

### FR-004 共通ショートカットの表示

現在の画面にかかわらず利用できるショートカットについては、

**「共通」**

などのカテゴリーとして表示できるようにする。

例：

```text
【共通】

Ctrl + N    新しいメッセージ
Ctrl + F    検索
Ctrl + Shift + F    高度な検索
```

---

### FR-005 カテゴリー分類

ショートカットをセクション別に分類する。

**MVP対象コンテキストの主なセクション**：

**メール一覧・メッセージ表示（共通）**：
- メッセージ移動
- メッセージ操作
- メッセージ管理
- テキスト選択・編集
- タグ・マーク
- 検索

**メール作成（固有）**：
- 送信
- 保存
- テキスト編集
- 添付ファイル
- 書式
- 挿入

**全画面共通**：
- 共通（全画面）

セクション構成はデータ（data/shortcuts.json）で管理する。

---

### FR-006 検索

ショートカット一覧が多数になることを考慮し、一覧内を検索できるようにする。

例：

```text
ショートカットを検索: [返信________]

R          返信
A          全員に返信
```

検索対象は、

- キー
- 操作名
- 説明

とする。

---

### FR-007 一覧の終了

`Esc` キーによって一覧を閉じ、一覧表示前のThunderbirdの状態に戻る。

---

### FR-008 フォーカスの復元

ショートカット一覧を閉じた後、原則として一覧表示前にフォーカスされていたThunderbirdのUI要素へフォーカスを戻す。

例：

```text
メール一覧
    ↓
Ctrl + ?
    ↓
ショートカット一覧
    ↓
Esc
    ↓
元のメール一覧の選択位置
```

## 8. ショートカット情報の管理

### 8.1 情報源

ショートカット情報は可能な限り、

1. Thunderbird本体の仕様
2. Thunderbird公式ドキュメント
3. WebExtension API
4. 必要に応じてThunderbirdソースコード

を基準とする。

個人ブログなどの情報を唯一の情報源にはしない。

---

### 8.2 ハードコード方式

初期バージョンでは、ショートカット情報をJSON等のデータファイルとして管理する方式を検討する。

例：

```json
{
  "context": "message-list",
  "shortcuts": [
    {
      "key": "Enter",
      "description": "メッセージを開く"
    },
    {
      "key": "Delete",
      "description": "メッセージを削除する"
    }
  ]
}
```

これにより、UIとショートカット情報を分離する。

---

## 9. バージョン差への対応

ThunderbirdではバージョンによってショートカットやAPIの仕様が変更される可能性がある。

そのため、ショートカット情報には必要に応じてThunderbirdバージョン情報を持たせる。

例：

```json
{
  "minVersion": "128",
  "maxVersion": null,
  "context": "message-list",
  "shortcuts": []
}
```

初期バージョンでは、対応するThunderbirdのバージョン範囲を明確にする。

## 12. `Ctrl+Shift+H` の採用理由

本アドオンの当初の想定ショートカットは `Ctrl + ?` である。

しかし Thunderbird WebExtension API の制限により、`?` や `/` などの記号キーは `manifest.json` の `suggested_key` で直接指定できない。

そのため、実装では **`Ctrl+Shift+H` を既定ショートカットに採用した**。

- ユーザーの利便性：日本語キーボード・USキーボードの両方で確実に入力可能
- Thunderbird との互換性：確実に認識される標準的なショートカットキー
- 将来の改善：Thunderbird が標準キーボード設定機能を提供すれば、ユーザーが変更可能

初期バージョンでは変更機能は提供しない。将来の拡張で設定画面の追加を検討する。

本アドオンの導入によって、

- メール送受信
- メール閲覧

## 18. 開発上の重要課題

本アドオンで最も重要なのは、UIそのものではなく、

> **「現在のThunderbirdの状態をどこまで正確に判定できるか」**

である。

特に以下を調査する必要がある。

1. Thunderbird WebExtensionから現在のウィンドウ状態を取得できるか
2. 現在のタブの種類を判定できるか
3. メール一覧・メッセージ表示・作成画面などを区別できるか
4. 現在のフォーカス位置を取得できるか
5. Thunderbird本体のショートカット情報をAPIから取得できるか
6. 取得できない場合に、公式情報をデータベース化する方法
7. `Ctrl + ?` を確実に検出できるか
8. スクリーンリーダーでダイアログを適切に操作できるか

特に **5番が重要な技術調査項目**となる。

Thunderbirdが「現在利用可能なショートカット一覧」をAPIとして提供していない場合、

> 「現在のコンテキストを判定 → アドオン側で対応するショートカット一覧を選択」

という方式が現実的になる。

### 実装時の重要判断

#### 1. `Ctrl+Shift+H` の採用

要件では `Ctrl + ?` の提案がありましたが、Thunderbird WebExtension API の制限により実装不可能です。

Thunderbird の `manifest.json` の `suggested_key` では、以下の理由から `?` や `/` などの記号キーを直接指定できません：

- WebExtension 標準仕様による制限
- キーボードレイアウト（日本語キーボード vs US キーボード）の互換性問題

そのため、実装版では **`Ctrl+Shift+H`** を既定ショートカットとして採用しました。

- **利点**:
  - 日本語・US キーボードの両方で確実に入力可能
  - Thunderbird 本体で既に検証済みの標準的なショートカット
  - ユーザーが「アドオン設定」で変更可能（Thunderbird 標準機能）

#### 2. コンテキスト判定の実装方式

Thunderbird WebExtension API は、現在のコンテキスト情報を直接提供する API を提供していません。

そのため、以下の方式を採用しました：

**優先度順のコンテキスト判定**:

1. **URL 解析（第一優先）**:
   - `about:calendar` → カレンダー
   - `about:addressbook` → アドレス帳
   - `about:tasks` → タスク
   - `mailbox://`, `imap://`, `message://` → メール

2. **ウィンドウタイトル解析（第二優先）**:
   - タイトルに含まれるキーワード（"Calendar", "Contacts", "Tasks" など）から判定
   - 複数言語対応（日本語、英語など）

3. **デフォルト判定**:
   - 判定できない場合は「共通」コンテキストを適用

この方式により、Thunderbird の仕様変更や複数ウィンドウ状況にも対応できます。

#### 3. JSON ベースのショートカット管理

Thunderbird 本体がショートカット API を提供していないため、`data/shortcuts.json` にショートカット情報をハードコード管理する方式を採用しました。

```json
{
  "common": {
    "title": "共通",
    "shortcuts": [
      {
        "key": "Ctrl + N",
        "description": "新しいメッセージ",
        "section": "基本操作"
      }
    ]
  },
  "mail": { ... },
  "calendar": { ... },
  "address-book": { ... },
  "tasks": { ... }
}
```

**メリット**:
- UI と情報の分離が明確
- メンテナンスが容易（新ショートカット追加時に JSON のみ修正）
- 将来的に多言語対応が容易
- ユーザーによるカスタマイズ拡張が可能（次バージョン以降）

### 将来の拡張予定（v2.0.0 以降）

以下の機能は、初期バージョンでは実装していません。将来のバージョンアップで対応予定です。

- **設定画面**: ショートカットキーの変更、表示するカテゴリーの選択

## 22. プロジェクトの最終目標

最終的には、

> **Thunderbirdを操作していて「この操作のショートカットは何だろう？」と思った瞬間に `Ctrl + ?` を押せば、その時点で利用可能なショートカットを確認できる**

状態を実現する。

ショートカットをユーザーに暗記させるのではなく、

**「必要なときに必要な情報へすぐアクセスできる」**

ことを本アドオンの基本思想とする。

特にキーボード操作やスクリーンリーダーを利用するユーザーにとって、Thunderbirdの操作方法を学習するための「インタラクティブなショートカットリファレンス」となることを目指す。
